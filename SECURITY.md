# Security Policy

## Reporting

Use GitHub's private vulnerability reporting: open this repository's Security tab and select **Report a vulnerability**. Do not open a public issue for a security vulnerability.

## What to expect

Reports are reviewed on a best-effort basis. This open-source project is maintained by an individual. No deadline or financial reward is promised.

## Supported versions

The current `main` branch is supported. Security fixes are not backported to older tags.

## Scope

This repository contains the static content for context-stack.org. In scope: content that misstates what the project claims, links that resolve somewhere unintended, and anything in the published pages that could mislead a reader about the project's conformance status.

The reference gateway and the MCP endpoint are separate repositories with their own security policies. Report vulnerabilities in third-party dependencies to the relevant upstream project.
